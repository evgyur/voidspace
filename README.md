# Voidspace 0.1.0

Быстрый нативный анализатор занятого места для Windows 10/11, написанный на Rust.

## Возможности

- потоковый treemap: интерфейс заполняется во время сканирования;
- непрерывный watcher и автоматический пересчёт после изменений;
- мелкие объекты собираются в интерактивную правую колонку `OTHER`;
- фильтры `name`, `ext`, `path`, `type`, `size`, `allocated`, `attr` с `AND/OR/NOT`;
- Pause/Resume, Rescan, zoom и история навигации;
- перенос в Корзину и безвозвратное удаление с точным подтверждением `DELETE`;
- snapshot `.voidspace` с zstd и BLAKE3;
- экспорт CSV, JSON, HTML и TXT;
- Turbo является основным режимом: приложение сразу получает права администратора и не открывает второе окно.
- верхняя кнопка `X:\ ▾` открывает список дисков с названием, объёмом и свободным местом; уже открытый корневой диск активирует существующую вкладку;
- hover временно показывает содержимое крупной папки внутри её плитки;
- один клик закрепляет раскрытие, двойной клик разворачивает папку на весь treemap;
- `← BACK`, breadcrumb и `Alt+←` возвращают к родительской папке;
- каждая видимая плитка показывает размер, а неподписываемая мелочь собирается в `OTHER`;
- Unbounded, Golos Text и JetBrains Mono встроены в приложение и одинаково работают без интернета.

## Запуск

Распакуйте ZIP и запустите `voidspace.exe`. Установка не требуется. Windows один раз покажет UAC-запрос для этого запуска, после подтверждения Voidspace работает в Turbo в том же окне. `voidspace-elevated.exe` должен оставаться рядом с основной программой.

## Безопасность удаления

Voidspace запрещает удаление корня диска и reparse/symlink-целей, дедуплицирует вложенные выборы и повторно сверяет полный manifest непосредственно перед исполнением. Любое появление, исчезновение или изменение объекта после подтверждения отменяет операцию. Безвозвратное удаление требует ввести `DELETE`.

## Turbo

В версии 0.1.0 Turbo — основной режим приложения: UAC-повышение плюс привилегированный Win32 traversal в одном окне. USN journal acceleration пока не заявляется как работающая и не имитируется.

## Сборка из исходников

Требуются Rust 1.98 stable, MSVC Build Tools и Windows SDK.

```powershell
powershell -ExecutionPolicy Bypass -File scripts\package.ps1
```

Команда запускает fmt, clippy, все тесты, release build, temp-root smoke и создаёт `dist\Voidspace-0.1.0-windows-x64.zip`.
